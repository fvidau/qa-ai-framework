# QA AI Framework – Banking API Context

## System Under Test
Banking API that handles:
- authentication
- balance inquiry
- money transfers
- transaction status

## Business Goal
Ensure safe, consistent, and reliable money movement.

## Critical Flows
1. Login
2. Check balance
3. Transfer money
4. Validate transaction

## Main Risks
- duplicate transactions
- incorrect balances
- unauthorized access
- inconsistent transaction states
- slow responses in critical flows

## QA Strategy
Focus on:
- API validation
- negative scenarios
- data consistency
- business-critical flows
- performance risk
- basic security checks

## AI Instructions
When generating outputs:
- prioritize business impact
- include edge cases
- identify risks
- avoid generic test cases
- structure responses clearly
